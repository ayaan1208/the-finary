# THE FINARY — product note

## One sentence
A personal daily intelligence agent that turns what’s happening in the world into information, learning, and skill development relevant to you.

## Problem
Commute / spare time gets wasted on scrolling. People want to stay informed **and** improve skills, but news apps and courses live in separate silos.

## Solution loop
```
Read → Understand → Learn → Practice → Improve → Repeat
```

Today’s edition is not only headlines. It connects events to a learning chain (especially AWS SAA) and ends with drills.

## What we are NOT building
- Not “another personalized news app”
- Not a full Duolingo replacement
- Not a generic ChatGPT wrapper with a fancy name

## Validation focus
Keep the product idea universal (“get what you want”), but prove the loop first with people who want career/skill growth from real-world information (survey → retention → willingness to pay).

## Current status
Personal prototype (Cursor Automation + PDF email). Public repo for friends / early feedback.
